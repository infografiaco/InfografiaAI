# Messaging — InfografiAI

## Core message hierarchy

**1. Headline (capability-led, used everywhere public-facing)**
"AI is the production capability. Creative direction is the product."
Alt: "Directed, not generated."

**2. Sub-line (introduces the hybrid method, still capability-first)**
"15+ years of design, motion and film craft — now directing generative pipelines instead
of just a camera."

**3. Proof line (where credibility needs to land fast — e.g. enterprise/government context)**
"The same studio behind [Home Affairs / CSIRO / Transport for NSW], applying that rigor
to generative production."

**4. Cost/speed line (used in proposal, pitch, and technology/brand segments — NOT led with)**
"What used to need a traditional production budget is now a genuinely viable brief."

## Messaging pillars

### Pillar 1 — Direction over generation
The differentiator is never "we can use Higgsfield/Kling/ComfyUI." It's that the output is
storyboarded, camera-choreographed and art-directed with the same intent as traditional
production — continuity, consistency, and a reason for every shot, not a lucky prompt.

### Pillar 2 — Hybrid, not pure-AI
Never claim "100% AI generated" as a virtue. The message is the pipeline: 3D → AI
transformation → traditional compositing, sound, edit. This is explicitly positioned
against pure prompt-to-video output.

### Pillar 3 — Borrowed rigor, new register
InfografiAI is not a discount version of Infografia and not a disconnected startup. It's
the same studio's standards applied to a more experimental, cinematic creative register.

### Pillar 4 — Capability unlocks access, not corners cut
When cost/speed is mentioned, it is always framed as an unlock ("this is now possible"),
never as a discount ("this is now cheaper"). Same message, opposite implication — the
second one commoditises the work.

## Words to use
directed / crafted / composed / choreographed / calibrated / constructed / considered /
hybrid / pipeline / continuity / consistency / intentional / systemised

## Words to avoid
cutting-edge / disruptive / revolutionize / game-changing / powered by AI / next-gen /
seamless AI magic / cheap / fast turnaround (as a headline claim) / limitless

## Sample messaging by touchpoint

- **Site hero:** "Directed, not generated." + one-line sub on hybrid craft.
- **Reel intro card:** No claim at all — let the process breakdown (storyboard → AI → final)
  make the argument visually before any copy does.
- **Pitch deck opening line:** "We've spent 15 years making complex things clear. This is
  what that looks like directing generative production."
- **Case study framing:** Always show the pipeline, not just the output — process is proof.
