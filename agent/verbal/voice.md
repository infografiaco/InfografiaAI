# Voice — InfografiAI

## Voice in one line
A director explaining a decision, not a startup pitching a feature.

## Traits (from section 13, translated into voice)

| Trait | Sounds like | Doesn't sound like |
|---|---|---|
| Intelligent | Precise, specific, technically literate | Jargon-dense or academic |
| Experimental | Curious about process, shows working | Chaotic or unfinished |
| Cinematic | Visual, paced, restrained | Overwritten or purple prose |
| Technological | Names real tools/methods plainly | "Powered by AI" marketing-speak |
| Designed | Considered, economical with words | Minimalist to the point of vague |
| Slightly strange | Willing to be specific and odd (the USB-camera-move idea) | Quirky-for-quirky's-sake |
| Contemporary | Current without chasing trend language | "Disruptive," "game-changing," etc. |

## Sentence-level rules
- Short declarative sentences over long persuasive ones. Let the work argue the case.
- Name real tools and real methods (ComfyUI, Higgsfield, camera choreography) rather than
  abstracting into "cutting-edge technology."
- Avoid selling language entirely where possible — describe the process, let capability
  speak for itself. This is a studio, not a SaaS product.
- First person plural ("we") for the studio voice; avoid "I" except in founder-attributed
  content (bios, talks, personal case-study framing).

## Reference test
Before publishing any InfografiAI copy, check it against messaging.md's word lists
(use / avoid) and against this question: "Does this describe direction, or does it just
claim AI capability?" If it's the latter, cut it.

## Example — before / after

**Before (generic AI-studio voice, avoid):**
"We're revolutionizing content creation with cutting-edge generative AI, delivering
seamless next-gen visuals at record speed."

**After (InfografiAI voice):**
"Fifteen years of directing cameras. Now we direct generative pipelines the same way —
shot by shot, with a reason for each one."
