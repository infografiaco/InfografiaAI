# Logo

The mark is a crossbar-less A with a dial at its base. A slice is cut out of the dial as its pointer. It came out of the website: the dial was built first as the site's control, and the mark puts that dial into the A.

## Rules

- Write the name **infograf/ai**: lower case, with the slash.
- One colour only: #111111 on light pages, #FFFFFF on dark pages. On the website home it is pressed in light grey into the white panel.
- Keep it small with plenty of space around it.
- Never emboss, box, outline, add effects to, recolour or redraw it. No blue pointer: the slice stays cut out.
- Never ask an image model to draw it. Place the vector after generation.

## History

1. 26 variations generated from the brand bible through Fuser.
2. IΛI chosen and redrawn as vector for Assignment 3 (`history/iai_assignment3_embossed.png`).
3. Building the website's dial suggested a stronger mark: the dial put into the A. A blue pointer was tested and removed. Refined in Illustrator.
