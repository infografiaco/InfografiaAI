# Cinematic trailer

`trailer_preview_25s_1080p.mp4`: the 25-second preview cut, 16:9, 1080p, with sound. `trailer_poster_frame.jpg` is its cover frame.

## The piece

"Infografia, enhance_". The brand's summary piece. The Director is studied piece by piece in the dark: hair, relief, cables, the visor. Then the world turns white.

On-screen supers, in order:

1. Infografia / Enhance
2. Fifteen years / of craft
3. Film / Design / Motion
4. Now / directed
5. Every frame / directed
6. The Director

## Rules

- Titles are set in the edit with real fonts, in the clear side of every frame. Never ask the video model to render text.
- Only the visor is glossy. Everything else stays matte. No glow, sparkle or particles.
- Build from approved stills: a start frame for every shot, made with the character sheet as the first reference, before any motion.

## How it was made

- A storyboard and animatic first, then an approved start frame for every shot.
- Start frames in GPT Image 2; motion in Seedance 2.5; masks with Higgsfield's background remover; score in ElevenLabs.
- The first 90-second particle and fluid build was too much for AI video; the story was cut shorter and simpler.
