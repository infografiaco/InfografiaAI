# Visual layer

Working visual assets and rules for infograf/ai.

| Path | What it is |
|---|---|
| `poster-system-skill.md` | The poster system: character, tone, type, logo, layout per ratio, prompt pattern |
| `governance-prompt.md` | Scored brand check to run on any generated image |
| `title-sequence/brief.md` | Stand-alone brief for the "Building the Director" title sequence |
| `logo/` | The mark and lockups as vector and PNG, usage rules, and the logo history |
| `website/` | The website concept, screens of the working prototype, and its build notes |
| `trailer/` | The cinematic trailer: 25-second preview, cover frame and how it was made |
